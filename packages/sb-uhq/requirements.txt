# Selfbot EtherSelf — discord.py-self
# ⚠️ discord.py-self s'importe sous le nom `discord` (incompatible avec discord.py officiel :
#    ne pas installer les deux dans le même environnement).
# L'extra [voice] (PyNaCl) est conservé même si le selfbot n'utilise plus de
# couche audio : il ne coûte rien et laisse la porte ouverte à un usage vocal.
#
# 🔒 Version ÉPINGLÉE volontairement. Cette bibliothèque non officielle a le
# contrôle total du compte (token, gateway, requêtes REST) : c'est la plus
# grosse surface d'attaque de chaîne d'approvisionnement du projet. Avec une
# borne `>=`, un simple `pip install -r` pouvait tirer une version publiée
# entre-temps sans relecture. Monter la version doit rester un geste explicite,
# après avoir regardé le diff en amont.
discord.py-self[voice]==2.1.0

# 🔒 Planchers relevés pour raisons de sécurité : la borne basse d'origine
# (`>=3.9`) laissait `pip install -r` accepter une version déjà installée
# criblée d'avis publiés depuis. aiohttp sert ici de serveur HTTP (le bridge)
# ET de client : les correctifs de request smuggling (GHSA-9548-qrrj-x5pj,
# GHSA-8495-4g3g-x7pr), de fuite d'en-têtes sur redirection cross-origin
# (GHSA-966j-vmvw-g2g9) et de DoS sur corps de requête nous concernent des
# deux côtés. 3.14.3 est la première version sans avis connu.
aiohttp>=3.14.3

# GHSA-mf9w-mj56-hr94 : suivi de lien symbolique dans `set_key`, corrigé en 1.2.2.
python-dotenv>=1.2.2

# Pas d'avis connu ; plancher aligné sur la version réellement testée.
psutil>=7.0
